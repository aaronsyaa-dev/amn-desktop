## Demande pour la navigation de S1 (retirée de l'Accueil, décision de Harun)

La barre latérale de l'Accueil est supprimée. Ce qu'elle apportait est à porter par la navigation de S1, avec des sources qui existent déjà (aucun appel nouveau) :

- **Des compteurs sur les modules**, calculés d'après les données réelles :
  - `/agenda` : rendez-vous encore à venir aujourd'hui (`useAppointments`, `appointmentEnd`) ;
  - `/tasks` : mes tâches ouvertes (collection `tasks`, `assigneeEmail`) ;
  - `/relances` : factures en retard (`useInvoices`, `isOverdue`) ;
  - `/priorites` : mes priorités du jour non faites (collection `dailyPriorities`) ;
  - les autres modules : les nouveautés de l'équipe par onglet (`useActivity().unseen`, déjà tenu par `ActivityContext`) ;
  - la famille d'un module vient du registre de S1 (`familleDe`).
- **Un bloc « En ligne »** : qui est sur quel module, avec la minute de grâce « vient de partir ». Source : `useRegards()` (`src/state/RegardsContext.tsx`), qui respecte déjà le réglage « Montrer ma présence ». Noms tirés de `useProfilesOptionnel().profileFor(email)`. Le libellé du module se déduit du chemin (`moduleDuChemin`) et du catalogue (`libelleNav`).
- Le code que j'avais écrit pour cette barre est dans l'historique de la branche (`91aabc3`, `src/refonte/accueil/useAccueil.ts` et `AccueilVivant.tsx`), si S1 veut le reprendre.

## Finitions faites dans la zone (carte blanche)

- **États honnêtes** : pendant le chargement, des gabarits et aucun message ; hors ligne, une phrase claire, pas de tuile ni de bouton blanc (un chiffre calculé sur un miroir peut-être incomplet serait faux) ; compte « vide » seulement si la synchronisation a répondu.
- **Premier jour** : trois étapes qui se cochent toutes seules, une phrase d'aide, et le bouton blanc devient « Commencer : … ».
- **Le message d'Ajmani mène quelque part** : un lien « Ouvrir » vers le point critique, la relance ou le module suggéré. Le bouton blanc ouvre le point critique en priorité. Le détail de l'alerte s'affiche sous le message.
- **La barre Ajmani envoie** : Entrée ouvre le panneau et lui transmet le texte tapé (par l'API publique `open` et `sendMessage`, sans toucher `src/assistant/**`). Texte d'invite court sur téléphone.
- **Raccourci selon le poste** : ⌘J sur Mac, Ctrl+J sinon (c'est déjà ce que fait l'assistant), dans la barre et dans les astuces.
- **Pluriels accordés** : « 1 jour », « 1 ligne masquée », « 1 faite cette semaine ».
- **Accessibilité** : le titre de la page est la salutation (h1) ; « x sur y fait » est annoncé poliment ; le focus revient au bouton « Ajouter une ligne » après un ajout ou Échap, et passe à la case voisine quand on masque une ligne ; le bouton « masquer » reste visible (contraste mesuré) ; les toasts ne s'effacent pas tant qu'on les survole ou qu'ils ont le focus ; Échap ferme le lancement par la pile des calques (`check:clavier` l'exigeait).
- **Performance** : le retard de chaque facture n'est calculé qu'une fois (avant, deux fois, en O(n²) avec les avoirs) ; la famille d'une route se lit dans une table construite une fois ; rien n'est calculé pour la barre supprimée.
- **Mouvement** : les gabarits animés suivent le réglage (les boucles CSS sont coupées en « Réduit » et « Aucun »).
- **Largeur** : l'Accueil est centré, 1180 px au plus.

## Points à trancher

- **Les tâches « faites » d'aujourd'hui** sont celles dont la date de modification est aujourd'hui : une tâche terminée hier puis commentée aujourd'hui y apparaît. Il n'existe pas de date de fin de tâche dans la donnée ; une vraie date demanderait un champ côté amn-api.
- **« Module oublié » reste une rotation** (revue hebdo, routines, journal de bord, objectifs) : l'app ne garde aucune trace des visites. Elle pourrait venir de S1 (modules récents), si la navigation les compte.
- **Le premier bouton du lancement** (« Cliquer pour passer ») n'apparaît qu'au tout premier lancement du poste.
- **`check:encres` échoue sur un fichier de S3** (voir plus haut) : à corriger par S3 ou le CO.
- **L'emplacement `ajmani={…}` de `ResumeDeNuit` (S3)** reste à retirer ou à brancher sur la barre ⌘J : zone S3.
